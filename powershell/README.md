# PowerShell Examples

These scripts are starter examples for a lab domain. Review and customize them before running. Run only in your isolated lab with an account authorized to administer Active Directory.

- `create-ou-structure.ps1` creates example organizational units.
- `create-lab-users-template.ps1` is a template for creating a small set of test accounts.

Do not publish real passwords or personal user information. The user-creation template prompts for a password at runtime and does not store it in the script.
