# Identity and Access Management Notes

Use this page to document security controls that you actually configured and tested in the lab.

## Topics to investigate

- Separate standard user accounts from administrative accounts.
- Use security groups to assign access rather than granting permissions individually where practical.
- Apply least privilege.
- Use a strong password policy appropriate for the lab.
- Configure account lockout settings and document the values.
- Limit membership in privileged groups.
- Disable or remove unused test accounts.
- Avoid using Domain Admin credentials for routine workstation activity.
